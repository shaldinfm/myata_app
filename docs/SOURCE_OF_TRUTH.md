## Правила на будущее

1. Разработка: свежий клон GitHub → ветка → PR → merge в `main`. Прямые пуши в `main` — нежелательны.
2. Релиз: только из `main`, только владельцем, только по явному GO; см. `docs/RELEASE_SIGNING.md`.
3. Папки D/A/B не редактировать; при необходимости данных из них — копировать наружу, не менять на месте.
4. Секреты (пароли подписи, keystore, токены) — никогда в git, никогда в issue/PR/логи.
