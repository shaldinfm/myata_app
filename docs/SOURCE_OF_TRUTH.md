Сравнение проводилось на свежем клоне GitHub в отдельной временной папке; отличия только в переводах строк (CRLF/LF) исключены (`diff --strip-trailing-cr`).

- **B — прямой git-родитель C** (`e25ddd4` — родительский коммит `50b897d`), рабочее дерево чистое, локальных правок нет. Ценности не несёт.

## Правила работы на будущее

1. **Разработка ведётся только от GitHub `main`** — через свежие клоны или единственный официальный рабочий клон.
2. **Не работать в копиях A и B.** Не редактировать файлы в этих папках.
3. **Не перезаписывать старые локальные копии** (никаких pull/checkout/sync «поверх» A и B).
4. **Архивировать/переименовывать A и B — только после явного решения владельца.** До этого они остаются на месте как исторические снапшоты.
5. Изменения — через ветки и PR; после подтверждения стор-версии пометить соответствующий коммит тегом.
