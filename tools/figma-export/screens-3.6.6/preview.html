PROPOSAL - awaiting visual approval. Not implemented in Android. Generated from spec.json; both themes come from one node tree with the token table swapped.

Таймер сна

Таймер сна · выбор sleep-timer-select 358×424

No option is preselected. A preset starts the timer and closes the sheet; 'Своё время' opens the picker instead.

Таймер сна · своё время sleep-timer-custom 358×398

Hours and minutes, so durations past an hour are expressible. The preview line resolves the duration to a wall-clock time before anything is committed.

Таймер сна · своё время, ошибка sleep-timer-custom-invalid 358×398

0 ч 0 мин is the only invalid input. Установить is disabled rather than accepting it and failing later, and minus is disabled at zero.

Таймер сна · активен sleep-timer-active 358×505

Reopening the sheet while a timer runs shows this state. The remaining time is computed from the stored absolute end time, never from a counter that restarts.

Таймер сна · активен, своё время sleep-timer-active-custom 358×505

A confirmed custom duration behaves exactly like a preset: absolute end time persisted, remaining time shown, cancellable, survives backgrounding and process recreation, and does not resume after a reboot.

Меню плеера · таймер активен sleep-timer-menu-active 260×264

The canonical menu is 206 wide, which cannot hold a label plus a trailing value. Widened to 260. This is the only change proposed to the existing menu - both rows stay.

Таймер сна · отменён sleep-timer-cancelled 358×56

Composited over the Player, 16px from the sides, above the mini player. Not a screen.

Таймер сна · сработал sleep-timer-completed 358×56

Shown once when the timer fires and playback stops. 'Продолжить' resumes; nothing resumes on its own, and nothing resumes after a reboot.

История эфира

История эфира · список history-content 390×852

Rows are variable height and never truncate. Two of the eight here wrap to a second line on purpose so the behaviour is reviewable. The time sits on the title's first line rather than drifting to the middle of a tall row. One trailing action, the canonical Collection control - there is no History-specific find icon.

История эфира · загрузка history-loading 390×752

Every horizontal anchor matches the loaded row: time at 13, art at 60, text at 116, action at 305. Placeholders for all four, including the trailing action, so nothing appears or shifts sideways when the data lands.

История эфира · пусто history-empty 390×496

Shown when the endpoint answers with an empty list - distinct from the error state below.

Найти трек · общий шит find-track-sheet 358×366

One find-track pattern shared by Broadcast History, the player menu and Collection. Collection adds a divider and a destructive row below these four; nothing else differs.

История эфира · ошибка history-error 390×496

Shown on a network or HTTP failure. Retry re-requests; it does not clear a cached list.

Коллекция

Коллекция · действия с треком collection-track-sheet 358×447

Replaces the per-track inline button. Four services, a divider, then the destructive action last and separated - the same shape as the canonical 'Найти трек' sheet it extends.

Коллекция · меню экспорта collection-overflow-menu 260×160

Opens from the TopAppBar overflow. Replaces the permanent 'Экспортировать список' button in the header, which costs 88px of vertical space on every visit for an action used rarely.

Аккаунт

Вход auth-sign-in 390×576

Revised from PR #23: same flow, canonical colours and type. Sign-in is optional everywhere - the app must stay fully usable without an account.

Создание аккаунта auth-create-account 390×596

Профиль · гость profile-guest 390×700

Guest is a first-class state, not a degraded one. Registration is optional and there is no wall anywhere: the card states what already works without an account, and the list below is what an account adds rather than what it unlocks.

Профиль · вошли profile-authenticated 390×692

Sign-out is destructive-styled but does not delete the local collection - that is stated in the confirm dialog, not here.

Выбор аватара profile-avatar 390×702

Sixteen predefined avatars. No photo upload in 3.6.6. Every cell is an asset slot - Material 3 avatar nodes are referenced if they exist in the file, and left as empty named slots for the owner to fill if not. Nothing here is a drawn approximation.
